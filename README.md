# XMotion-V1-Open-source-6-axis-robotic-arm-controlled-by-STM32-and-EtherCAT.
XMotion V1 is an open-source 6-axis robotic arm controlled by STM32 H7 and EtherCAT. It runs real-time motion control with fixed-point trajectory planning and 1 ms synchronization. This version focuses on embedded precision and serves as the foundation for the ROS-based XMotion V2.
